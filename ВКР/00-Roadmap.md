# Роадмап ВКР — безопасность браузерных LLM-агентов

Тема: защита памяти LLM-агента от отравления (provenance-контроль) в браузерных агентах, на фоне уже решённых origin- и argument-level угроз.

Статус по состоянию на 24.10.2026: research proposal принят научруком (Вероника Викторовна), ведётся модель угроз по методике ФСТЭК (Приложение 3), стенд ещё не начат.

Эти угрозы признаны актуальными в модели, но для них уже есть опубликованные решения — в дипломе не переделываются, берутся как baseline.

## Фаза 3 — Ядро работы: провенанс памяти (гэп, НЕ закрыт)

- [[Источники/Poison-Once-Exploit-Forever|Zou и др. — Poison Once, Exploit Forever]] — **центральная статья**. Описывает eTAMP-атаку (отравление памяти через обычный просмотр страницы, срабатывает позже на другом origin/сессии). Только атака, авторы прямо пишут об отсутствии защиты — это и есть предмет ВКР.

Задачи фазы:
- [ ] Детально разобрать сценарии eTAMP из статьи (раздел с экспериментами)
- [ ] Спроектировать схему provenance-меток для памяти (присвоение / сохранение / проверка при извлечении)
- [ ] Сопоставить с готовой архитектурой SOPGuard — как встроить метки памяти в тот же механизм распространения, что и origin-метки
