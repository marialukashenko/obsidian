# WASP

**Что сделано.** Открытый benchmark для измерения безопасности веб-агентов против prompt injection, построен на реалистичных сценариях (включая GitLab, Reddit) с измерением как успешности атаки, так и успешности выполнения легитимной задачи одновременно.

**Почему важно для ВКР.** Методологический образец для дизайна собственного эксперимента (Фаза 5 роадмапа): нужно будет так же парно измерять «защита снижает ASR» и «защита не ломает полезную задачу». Можно позаимствовать часть сценариев или их логику для своих тестовых страниц/задач (особенно сценарии, требующие доступа к нескольким origin — близко к тому, что нужно для group D по памяти).

**Статус:** вспомогательный источник для методологии эксперимента, не для архитектуры защиты.
