# WAAA! Web Adversaries Against Agentic Browsers

**Что сделано.** Систематизируют 20 атак на агентные браузеры, 18 из них доведены до рабочих PoC (демонстрация на реальных браузерных агентах).

**Почему важно для ВКР.** Дополнительный источник эмпирических данных для Раздела 5/6 модели угроз (способы реализации угроз, профиль нарушителя) — расширяет картину, заданную UW-статьёй ([[UW-Agentic-Browsers-SOP]]), конкретными техниками атак. Не является core-источником, но полезен для насыщения разделов модели угроз конкретными примерами и для литобзора в основном тексте (мотивация, почему origin-угрозы актуальны и разнообразны).

**Прочитать:** таблицу классификации 20 атак — удобно сопоставить с категориями способов реализации угроз по Приложению 2 Методики ФСТЭК.
