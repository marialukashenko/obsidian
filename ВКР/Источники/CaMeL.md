# CaMeL

**Что сделано.** Защита «по конструкции» (by design), вне модели: разделяет control flow и data flow — LLM используется только для планирования, а фактическое исполнение действий и обработка данных идёт через отдельный, детерминированный интерпретатор с явным контролем capabilities.

**Почему важно для ВКР.** Концептуальный источник для архитектурной идеи «слоя изоляции», который фигурировал в первой версии research proposal (направление A). Для текущей темы (provenance памяти) полезен как пример того, как можно вынести контроль за пределы самой LLM — та же логика применима к памяти: не доверять решению модели о том, что можно взять из памяти, а проверять это детерминированно на системном уровне.

**Статус:** фоновая архитектурная идея, не прямой baseline (в отличие от SOPGuard/PACT, не измеряет origin/argument напрямую, более общая концепция control/data separation).
