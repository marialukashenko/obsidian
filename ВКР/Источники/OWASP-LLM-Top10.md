# OWASP Top 10 for LLM Applications

**Что это.** Общепризнанный список главных классов угроз для LLM-приложений (Prompt Injection, Insecure Output Handling, Training Data Poisoning, и др. — состав списка обновлялся, нужно свериться с актуальной версией 2025/2026 года при чтении).

**Почему важно для ВКР.** Второй (вместе с MITRE ATLAS) дополнительный источник векторов атак для Раздела 6 модели угроз — более высокоуровневый и "каноничный" для индустрии, хорошо смотрится как co-citation с ATLAS в академическом тексте. Особенно релевантны категории Prompt Injection и (если есть в актуальной версии) категории, связанные с памятью/RAG-отравлением.

**Задача:** свериться с версией списка на момент написания модели угроз — состав категорий меняется между релизами.
