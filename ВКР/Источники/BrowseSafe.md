# BrowseSafe

**Что сделано.** Индустриальная (Perplexity) работа про модельные и архитектурные защиты браузерных агентов от prompt injection — комбинация детектора на уровне модели и архитектурных ограничений.

**Почему важно для ВКР.** Источник для сравнения в литобзоре: показывает индустриальный подход (modeling + architecture) в противовес чисто архитектурным академическим решениям (SOPGuard/PACT). Полезно сравнить именно с изоляцией по origin — чтобы в основном тексте явно аргументировать, почему для ВКР выбран детерминированный архитектурный путь, а не модельный детектор (который сам Perplexity признаёт неполным решением, т.к. гонка вооружений на уровне модели).

**Статус:** вспомогательный источник для литобзора/сравнения подходов.
