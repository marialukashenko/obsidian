# MITRE ATLAS

**Что это.** База знаний (matrix) тактик и техник атак на AI/ML-системы, по аналогии с MITRE ATT&CK, но для машинного обучения и LLM-систем (prompt injection, data poisoning, model evasion и т.д.).

**Почему важно для ВКР.** Компенсирует слабое покрытие ИИ-угроз в БДУ ФСТЭК — используется как дополнительный источник данных о способах реализации угроз (п. 2.3 «б» Методики ФСТЭК допускает использование дополнительных баз данных по векторам атак). В Разделе 6 модели угроз ("Способы реализации угроз") нужно явно сослаться на конкретные техники ATLAS, релевантные prompt injection и memory poisoning (например, категории, связанные с "LLM Prompt Injection" и "Data Poisoning").

**Задача:** выбрать 2–4 конкретные техники ATLAS, прямо соответствующие трём угрозам модели (origin, argument, память), и явно процитировать их ID в Разделе 6.
