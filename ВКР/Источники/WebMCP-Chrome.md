# WebMCP — Agent security considerations (Chrome)

**Что сделано.** Официальное руководство Chrome по безопасности при работе агентов с WebMCP (протокол, позволяющий сайтам явно объявлять "инструменты" для агентов, а не заставлять их парсить обычный UI). Обсуждают риски вроде скрытых/вредоносных tool-описаний, подмену инструментов.

**Почему важно для ВКР.** Вспомогательный, индустриальный контекст — показывает, что даже при "официальном" протоколе взаимодействия агент-сайт проблема provenance/происхождения данных и инструкций не исчезает, а меняет форму (вредоносный tool-описание вместо вредоносной HTML-страницы). Полезно для одного абзаца в литобзоре про то, что проблема не специфична для текущего поколения браузерных агентов и не будет решена сменой протокола.

**Статус:** контекстный источник, не для прямого цитирования в модели угроз.
