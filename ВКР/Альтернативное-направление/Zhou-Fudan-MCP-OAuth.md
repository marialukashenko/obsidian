# Zhou и др. (Fudan) — измерение OAuth в MCP

**Что сделано.** Просканировали 7973 живых удалённых MCP-серверов: 40.55% без аутентификации вообще; из 119 проверенных OAuth-реализаций — у всех минимум одна ошибка (325 суммарно), получено 9 CVE. Предложили классификацию из 9 классов ошибок (открытая регистрация клиентов, откат PKCE до plain, открытый redirect и др.).

**Статус.** Архив направления B (не выбрано для финальной темы). Может использоваться как пример для сравнения "уровней", на которых применяется та же логика provenance/происхождения (здесь — происхождение токена/клиента, а не данных агента).
