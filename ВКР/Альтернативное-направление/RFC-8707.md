# RFC 8707

**Что это.** Стандарт OAuth 2.0, определяющий параметр `resource`, позволяющий клиенту явно указать, для какого ресурса предназначен запрашиваемый токен — используется для привязки токена к аудитории (audience-binding), что предотвращает использование токена не по назначению.

**Статус.** Архив направления B — был частью плана "укреплённого эталона" (вместе с PKCE S256 и allow-list redirect_uri).
