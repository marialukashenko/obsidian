# AIP (Agent Identity Protocol)

**Что это.** IETF-драфт, предлагающий слой идентичности агента для протоколов MCP и A2A — чтобы запросы агента можно было криптографически связать с конкретным агентом/принципалом, а не только с OAuth-токеном.

**Статус.** Архив направления B. Был ориентиром для "укреплённого эталона" в этом направлении.
